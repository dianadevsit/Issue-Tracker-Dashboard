<h2>Issue Tracker App</h2>
<p>
  This is a full-stack issue tracker built with <strong>Python (Flask)</strong>,
  <strong>JavaScript</strong>, and <strong>SQLite</strong>. Users can submit, edit,
  and delete issue reports with priority tags and see them update live in the UI.
</p>

<h3>How to Run Locally</h3>
<ol>
  <li>Clone the repository</li>
  <li>Navigate to the project folder in your terminal</li>
  <li>Install Flask: <code>pip install flask</code></li>
  <li>Run the app: <code>python app.py</code></li>
  <li>Open your browser and go to <a href="http://127.0.0.1:5000" target="_blank">http://127.0.0.1:5000</a></li>
</ol>

<h3>Features</h3>
<ul>
  <li>Submit new issues with title, description, and priority</li>
  <li>View all issues in a responsive UI</li>
  <li>Edit or delete issues in-place</li>
  <li>Styled priority badges (Low, Medium, High)</li>
</ul>

<h3>Tech Stack</h3>
<ul>
  <li>Python (Flask)</li>
  <li>JavaScript (Vanilla + Fetch API)</li>
  <li>SQLite (Local database)</li>
  <li>HTML + CSS (No frameworks)</li>
</ul>
